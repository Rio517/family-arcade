# Caribbean visual references

These files are durable art-direction references, not production-ready game
assets.

## `1732-herman-moll-west-indies.jpg`

- Title: *A Map of the West-Indies & c. Mexico or New Spain*
- Cartographer: Herman Moll
- Date: 1732
- Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:1732_Herman_Moll_Map_of_the_West_Indies_and_Caribbean_-_Geographicus_-_WestIndies-moll-1732.jpg)
- Original dimensions: 3,000 × 2,287 pixels
- Local SHA-256: `d58dd1e69bacf6525e7b3f4ff047fe938a7ebcea78518c1f5fa62985bbd427f8`
- Rights: public-domain work and faithful reproduction, as documented by the
  source page.

The map is later than the game's 1675 setting, so it is used for Caribbean
geography, coast/island relationships, chart texture, rhumb lines, and period
map composition—not as an exact 1675 political or navigational record.
