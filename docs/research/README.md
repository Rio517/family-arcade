# Research

Notes from looking into tools, libraries, and techniques we're *considering* —
not decisions (those graduate to [ADRs](../adr/)) and not designs for things
we've agreed to build (those live in [planning](../planning/)). Each note says
what the thing is, whether it fits this project, and what would make us
revisit.

- [2026-08-18-playcanvas.md](./2026-08-18-playcanvas.md) — can PlayCanvas
  replace Blender and/or three.js for our 3D? (Short answer: it replaces
  neither today — it's a three.js *alternative*, not a Blender one — but its
  collaborative browser editor is the thing to remember if we ever build a
  bigger 3D game.)
